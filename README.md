> **Статус: исследование и проектирование.** Рабочего бота и deployment пока нет. Рекомендуем TypeScript и Cloudflare Workers для минимальной сложности; итоговая проверка архитектуры продолжается. Расчётный масштаб: до 1000 пользователей с допустимой задержкой уведомлений 1–3 минуты. Нагрузочная проверка ещё не проведена.

## Зачем это нужно

Преподаватель переносит занятие в календаре. Студенту нужно получить напоминание о новом времени, а не искать последнее сообщение в чате.

Проект связывает два расписания, обычный и расширенный курс iOS-разработки, с личными настройками уведомлений. Календарь остаётся единственным источником расписания. Бот только читает его.

## Как это будет выглядеть

1. Студент запускает Telegram-бота и выбирает курс.
2. Выбирает напоминание, например за 30 минут или за сутки.
3. Получает время занятия, название и доступную ссылку.
4. Может посмотреть ближайшие занятия, сменить курс или выключить уведомления.

Пример будущего сообщения, не скриншот работающего продукта:

> 🔔 Через 30 минут занятие
>
> **Работа с сетью в iOS**
>
> Сегодня, 19:00 · Europe/Moscow
>
> Ссылка на встречу будет взята из календаря.

## Принципы

- **Нулевые регулярные расходы.** Рассматриваем тарифы с остановкой на лимите, без автоматического платного перерасхода.
- **Мало зависимостей.** Предпочитаем встроенные API Workers и прямые HTTP-запросы к Telegram; отдельно оцениваем библиотеку iCalendar.
- **Прозрачные ограничения.** Не обещаем доставку ровно в секунду или невозможность дублей при любом сетевом сбое.
- **Секреты отдельно.** Токены и приватные iCal-ссылки не попадают в репозиторий.
- **Одна логика расписания.** Мессенджеры подключаются отдельными адаптерами.

## Что уже выяснили

Для MVP рекомендуем TypeScript + Workers + D1 + минутный Cron + Queue + Workers Secrets. Очередь разделяет массовую доставку на небольшие пачки. Сохраняем расчёт на 1000 пользователей и целевую задержку 1–3 минуты; это ещё предстоит проверить.

Обычный Go-сервер нельзя просто загрузить в Cloudflare Workers: требуется Wasm и интеграция с API среды. Containers не подходят под требование $0. Workers, D1 и Queues остаются кандидатами; окончательного выбора нет.
